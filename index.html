    Créer une app sur dev.twitch.tv/console → catégorie « Game Integration » → copier Client ID + Secret

    Créer un compte sur themoviedb.org → Paramètres → API → demander une clé (gratuite)

    Créer une clé : console.cloud.google.com → projet → API et services → Activer « Google Books API » → Identifiants → Clé API.
    Recommandé : restreindre la clé aux référants HTTP chenzu-ai.github.io/* et localhost.

    Créer un compte BGG → boardgamegeek.com/applications → « Register Application » (usage non commercial) → générer le token. Sans token, l'API BGG refuse les appels (1 req/5s intégré).

    Créer un compte Discogs → Paramètres → Développeurs → générer un Personal Access Token (gratuit, 60 req/min authentifié). Sans le relais, Discogs reconnaît les CD/vinyles par code-barres.

    Le relais interroge Fnac + BnF (inaccessibles directement depuis un navigateur) via un micro-service gratuit Cloudflare Workers. Code et procédure : fichier worker.js du dépôt.

    Dernier recours de la reconnaissance : si <URL><ISBN>.jpg existe, la couverture est utilisée.

    📋 Cataloguing guide — the 7-step workflow (2-4 min/record)

    📋 Practical cataloguing guide

    3 principles: ① Scan first, never after (60-80% of fields in 10 s) · ② Structuring fields before free fields (medium → subtype → genre → carrier → edition lock 80% of rules and the shelfmark) · ③ The shelfmark is generated (🎯 button), never typed.

    Canonical order: 1. SCAN (10 s) → 2. STRUCTURING (30 s): medium → mediaSubtype → genre → carrier → editionType, each field filters the next → 3. FACETS (20 s): audience, language, region (video), accessibility — they drive the shelfmark → 4. SHELFMARK (2 s): 🎯, ≤ 35 chars, never hand-correct (except shortening) → 5. SUBJECTS (30 s): 1-3 RAMEAU subjects, 1 precise > 3 approximate, first = main subject → 6. RELATIONS (30 s): only if justifiable in one sentence (adapt, sequel, prequel, remake, translation, universe) → 7. CHECKS (10 s): genre/medium · shelfmark · subjects · relations. Fix errors, read warnings then decide.

    The 10 pitfalls: ① fixing scanned fields before structuring ones · ② typing the shelfmark manually · ③ 3 subjects "to be safe" · ④ unjustified relation · ⑤ confusing POC (pocket carrier) and POCHE-ED (pocket edition) · ⑥ comics filed as BD-FB (→ BD-COM) · ⑦ DLC catalogued alone (opus_parent required) · ⑧ each issue as a record (→ 1 title record) · ⑨ video region ignored (loan impossible) · ⑩ accessibility ignored for adapted documents.

    Time budget: book/comic/manga/music 2 min (max 4) · film/adapted doc 2.5 min (max 5) · series/video game/board game 3 min (max 6) · magazine 1.5 min (max 3) · heritage document 5 min (max 15). Over budget → save as-is: an 80% record beats a 100% one never finished.

    🔌 Automatic sources: books/comics/mangas → BnF, Google Books, Open Library, Fnac, Wikidata (fallback) · films/series → TMDB · video games → IGDB · mangas → AniList · board games → BGG (players, age, duration, complexity — token required in ☰→🔑) · music → MusicBrainz, **Discogs** (vinyls/CD fallback by barcode, token in ☰→🔑) · digital resources → **CrossRef** (DOI or title). On a record, type the title then 🤖 — everything is fetched from reference databases, the AI never guesses.

    🔌 API orchestration guide (where to fetch metadata per medium, source cascade, API keys): docs/orchestration-api.md

    📄 Full printable guide: aide/catalogage.html (French) — the 7 steps, per-family best practices (11), special cases (duplicates, related works, box sets, DLC), the catch-up strategy.

    Catch-up strategy (your 44 Simplissime + films + games): batches of 5-10 records with breaks (5 sessions of 20 min) · start with the easiest (books → films → series → video games → board games → heritage) · do not backfill subjects (curate by usage) · use the coherence audit as a work list. The real test: time your next 3 records.

    🚀 Getting started (5 min)

    🎬 Multimedia cataloguing — the 4 axes

    Each multimedia record is described on 4 independent axes + facets:

    1. Content type (the work): film, animation, anime, series, TV movie, documentary, report, concert, comedy…

    2. Physical carrier (the container): VHS, DVD, Blu-ray, Blu-ray 3D, Blu-ray 4K Ultra HD, vinyl 33/45rpm, audio cassette, CD, SACD, cartridge, streaming, digital purchase…

    3. Edition (the version): standard, special, collector, digipack, steelbook, box set (season, complete), anniversary, remastered, Director\u0027s Cut, extended…

    4. Numbering (the position): volume (V01), season/episode (S01E05), opus — « Volume » field.

    Facets: audience (TP, -12, -16…), region (Z1-Z4, A/B/C Blu-ray), audio version (VO, VF, VOST, MULTI), aspect ratio (16:9, 2.39:1), country, language — all dropdown lists.

    💡 AI can pick: photograph the back cover (📸) then 🤖 AI reads it — it extracts synopsis, credits AND readable facets (carrier, region, ratio, audio). You validate in the dropdowns.

    🎬 Movies: with a TMDB key (☰ → 🔑), type the title then 🤖 — director, cast, synopsis and poster come from the movie database. 🎮 Games: Twitch/IGDB key → studio, cover, genres.

    🎮 Video games — dedicated referential

    When the record Type is Video game, the lists switch automatically:

    • Content type = game genres (38): Action, Action-Adventure, Platform, Fighting, FPS, MOBA, Adventure, Point & Click, RPG, JRPG, Action-RPG, Tactical RPG, MMORPG, Roguelike, RTS, 4X, Simulation (management, flight, racing, sports, life), Puzzle, Music/Rhythm, Party, Educational, Arcade, Casual + themes (Horror, Survival horror, Sci-fi, Fantasy).

    • Carrier = game media: cartridge, CD-ROM, GD-ROM (Dreamcast), DVD-ROM, GameCube/Wii discs, Blu-ray (PS3/PS4), Blu-ray UHD (PS5/Xbox Series), UMD (PSP), floppy, Steam/GOG/Epic, PlayStation Store, Xbox Store, eShop, mobile, cloud gaming, subscription (Game Pass).

    • Edition = GOTY, Remastered, Remake, Compilation, Day One, Digital Deluxe, Complete — in addition to standard/collector/box set.

    • Platform (32): PC, PS5, PS4, PS3, PS2, PS1, PSP, Vita, Xbox Series, Xbox One, 360, Switch, Wii U, Wii, GameCube, N64, SNES, NES, DS, 3DS, GBA, Game Boy, Mega Drive, Master System, Saturn, Dreamcast, Atari 2600, Amiga, C64, mobile.

    • Game mode: solo, local/online multiplayer, local/online co-op, MMO, competitive (e-sport).

    🔢 Numbering: « Volume » field — OPUS01, S01E05, DLC01, SPIN, REM01 (2 digits for sorting).

    📚 Manga — dedicated referential

    When the record Type is Manga, the lists switch automatically:

    • Content type = demographic (the primary shelving criterion): Kodomo (children), Shonen (teen boys), Shojo (teen girls), Seinen (young adults), Josei (adult women), Seijin (adults). Record the original demographic (from the Japanese magazine), not the actual readership.

    • Carrier = Japanese editorial formats: prepublication magazine (Jump…), Tankobon (standard volume), Bunkoban (compact pocket), Kanzenban (complete edition, large format), A5/B6, Omnibus (multiple volumes in 1), digital, Webtoon (vertical reading).

    • Edition: Pocket, Perfect Edition (FR kanzenban), Reissue, Specimen — in addition to standard/collector/deluxe/box set/anniversary.

    • Reading direction: Japanese (right-to-left, original) or French (reworked).

    • Country: JP (manga), KR (manhwa), CN (manhua) — the Country field distinguishes the three traditions.

    • Thematic genres (Genre field): Action, Adventure, Romance, Comedy, Drama, Fantasy, Sci-fi, Horror, Mystery, Sports, Slice of life, Isekai, Mecha, Magical girl, Historical, War, Psychological, Cooking, Music, Martial arts, Yakuza, Yaoi/BL, Yuri, Bara, Ecchi.

    🔢 Numbering: T01, T01-T05, OMNI01 (omnibus), HS (side story), SP (special/artbook) — 2 digits for sorting.

    🎨 Comics / bande dessinée — dedicated referential

    When the record Type is BD, the lists switch automatically:

    • Content type = editorial family (drives shelving): Franco-Belgian album (recurring hero), Graphic novel (literary one-shot), Comics (US tradition), Strip collection, Webcomic, Documentary comics, Author/alternative comics.

    • Carrier = editorial formats: Hardcover album (Franco-Belgian), 48 CC format (historical standard), large/pocket, complete edition, omnibus, box, Comic book (US pamphlet), Trade Paperback, Hardcover (US), strip collection, digital, webtoon.

    • Edition: Collector complete edition, Deluxe — in addition to standard/collector/deluxe/box/anniversary.

    • Reading direction: Franco-Belgian (FB) and US Comics (US), in addition to Japanese (JPN).

    • Genres (Genre field): Action, Humor, Crime, Sci-fi, Fantasy, Fantastic, Historical, Western, Biographical, Autobiographical, Documentary, Romance, Drama, Super-hero, Youth.

    🔢 Numbering: T01, CYC01-T01 (cycle), T06/6 (end of cycle), OMNI01, HS, SP — a one-shot graphic novel stays unnumbered.

    📰 Magazines & newspapers — dedicated referential

    A new record Type: Revue / magazine / journal. The lists switch automatically:

    • Content type = editorial nature: Daily (Le Monde), Weekly (Télérama), Magazine (Paris Match), specialized Journal (scholarly), Bulletin, Directory, specialized press.

    • Carrier = distribution formats: paper, tabloid, berliner (Le Monde), broadsheet, bound volume, microfilm, fascicle, digital, website, app, database (Cairn).

    • Periodicity: daily → annual, irregular, special issue.

    • Collection state (essential in libraries): ongoing (active subscription), stopped, complete (since #1), partial (gaps), withdrawal planned.

    • Edition: subscribers, international, regional, special issue.

    🔢 Numbering: periodicals have an ISSN (8 digits) — ISBN/EAN field; each issue: N°1234-2024-10, VOL12-N°3 (scholarly), HS01, or date alone for dailies (2024-10-29).

    📖 Books — dedicated referential

    When the record Type is Livre (or empty), the lists adapt:

    • Content type = editorial family (drives fiction/documentary shelving): Novel, Essay, Biography, Autobiography/Memoirs, Documentary, Coffee-table book, Children\u0027s album, Poetry, Theatre, Practical guide.

    • Carrier = editorial formats: Trade paperback (grand format), Pocket, Hardcover, Fine format, Album, Semi-pocket, Box, EPUB, PDF, MOBI/Kindle, Audiobook, online reading.

    • Edition: Complete (series in 1 volume) — in addition to standard/collector/deluxe/box/anniversary/remastered/reissue/numbered.

    • Genres (Genre field): Crime, Sci-fi, Fantasy, Fantastic, Historical, Romance, Adventure, Humor, Drama, Philosophy, Religion, Science, History (non-fiction), Geography/Travel, Arts, Society/Politics, Textbook.

    🔢 Numbering: T01 (volumes), VOL01 (multi-volume essays), LIV01 (book of a work), OMNI01, HS, SP — a one-shot (single novel, single essay) stays unnumbered.

    📺 TV series — dedicated referential

    When the record Type is Série, the lists switch automatically:

    • Content type = families: Fiction series, Western animation, Anime, Mini-series, Serial, Soap opera, Web-series, Documentary series, Docufiction, TV movie, Reality show, Game show.

    • Carrier: VHS, DVD, Blu-ray, Blu-ray 4K UHD, Box sets (DVD/Blu-ray/4K), SVOD streaming, download, VOD, Catch-up (France.tv), Web.

    • New fields: Seasons (total), Episodes (total), Channel / broadcaster (TF1, Netflix, HBO…).

    • Edition: Season, Complete — in addition to collector/deluxe/anniversary/remastered.

    🔢 Numbering (Volume field): S01 (season), S01E05 (season+episode), EP001 (serials without seasons), INT (complete), PIL (pilot), HS, SP — 2 digits for sorting.

    🎵 Music — dedicated referential (PCDM)

    When the record Type is Musique, the lists switch automatically:

    • Content type = PCDM classes (the library standard replacing Dewey 780): 1 African-American (blues, jazz, soul, rap, reggae), 2 Rock & pop, 3 Classical (chamber, symphony, opera), 4 Electronic (house, techno), 5 Functional, 6 Film music, 8 French chanson, 9 World music.

    • Carrier: vinyl 33/45/78rpm, cassettes, 8-track, reel, DAT, CD, SACD, DVD-Audio, Blu-ray audio, MiniDisc, SHM-CD, Blu-spec, FLAC download, streaming (Spotify/Qobuz).

    • Formation: solo, duo, trio, quartet, orchestra, big band, choir, ensemble. • Main instrument: piano, violin, cello, guitar, saxophone…

    • Edition: Gatefold (vinyl), Box set, Extended — in addition to digipack/collector/deluxe/remastered/anniversary.

    🔢 Numbering (Volume field): OP.27 (opus, classical), VOL.3 (complete editions), ALB.5 (discography), TRACK.7, FACE.A (vinyl).

    🎲 Board games — dedicated referential (ESAR + BGG)

    When the record Type is Jeu de société / plateau, the lists switch automatically:

    • Content type = BGG types: abstract strategy, customizable (Magic, Warhammer), thematic, family (Catan), children\u0027s, party, strategy/eurogame, wargame.

    • ESAR classification (the library/game-library standard): E exercise (sensory, motor), S symbolic (pretend play), A assembly (building, puzzles), R rules (association, strategy, riddles…) — with the 20 sub-families.

    • Main mechanic (19): worker placement, action points, auctions, area control, bluff, co-operative, deduction, escape game…

    • Carrier: standard/small/big box, premium box, pouch, + dominant components (board, cards, dice, miniatures, tiles, GM screen), companion app, digital (BGA), Print & Play.

    • New fields: Players (2-4), Minimum age (3+→18+), Duration (-15→120+), Complexity (light/medium/heavy — BGG weight).

    • Edition: starter set, Kickstarter, Big Box, expansion, campaign, scenarios, demo.

    🔢 Numbering: VOL01 (range), EP01 (escape game), EXT01 (expansion), SAI01 — an expansion always links to its base game.

    💻 Software — dedicated referential

    A new record Type: Logiciel. The lists switch automatically:

    • Content type = functional families (13): System/Utility, Office suite, Graphics/DTP, Music, Video editing, Web development, Software development, Databases, Business/ERP, Educational, Cataloguing (Koha…), Security, Network.

    • Category: Proprietary, Open source, Freemium, SaaS. • License type: perpetual, subscription, site, volume, named, per-seat.

    • Carrier: CD/DVD-ROM, Blu-ray, USB key, floppy, download, SaaS, cloud, mobile app, webapp, license key. • Platform: Windows, macOS, Linux, Android, iOS, Web.

    • Edition: Professional, Enterprise, Education, Student, Home/Family, OEM (preinstalled), Trial, Free.

    🔢 Numbering (Volume field) = semantic versioning: MAJOR.MINOR.PATCH (e.g. 2.4.1), yearly version (2024.1), -beta/-rc suffixes. No superfluous zeros.

    🏛️ Heritage & special documents — 9 new Types

    Nine new record Types cover heritage, iconographic and digital collections. The lists switch automatically:

    • 🎼 Musical score: full score, choral, reduced (piano-vocal), conductor, separate part, study edition — paper/braille/MusicXML. Numbering: OP., K. (Mozart), BWV (Bach), ISMN.

    • 🗺️ Map / plan / atlas: map, city plan, atlas, globe, celestial sphere, satellite, nautical, aeronautical, relief.

    • 📷 Photograph: B&W, colour, analog, native digital, aerial, photojournalism, studio, fine art — print, negative, slide, RAW, glass plate, album.

    • 🖼️ Print / poster: woodcut, etching, litho, serigraphy + posters (cinema, show, advertising, politics) — fine art papers.

    • 📜 Manuscript / archive: modern, medieval, correspondence, journal, draft, fonds — parchment, papyrus, digitization.

    • 🎓 Thesis / official doc: doctorate, master, HDR, dissertation, report, government publication, official bulletin.

    • 🗂️ Ephemera: leaflet, flyer, menu, postcard, programme, invitation, greeting card.

    • 🎸 Object / instrument / kit: musical instrument, artefact, educational tool, Lego/Kapla, kits (reading, thematic), kamishibai, scientific equipment.

    • 💾 Digital resource: database (Cairn), platform, e-journal, digital library, podcast, radio show, archived website, mobile app, VR/AR.

    ♿ Adapted documents: the Accessibility facet (braille, easy-read, large print, audio description, SDH, sign language) applies to ALL types — a book can be large print, a film audio-described.

    ⚖️ Automatic coherence checks

    On save, 56 rules check record consistency (⚠️ warnings, 🚫 errors): VHS after 2006, miniseries >6 episodes, kodomo + adult content, pocket + luxury, braille on video, daily + monthly, invalid Blu-ray UHD zone, webtoon collector, daily directory…

    Documented business thresholds: VHS ≤ 2006 · Blu-ray 3D ≤ 2018 · glass plate ≤ 1950 · parchment ≤ 1500 · print < 1500 = heritage · easy-read ≥ 2009 · digital maps < 1800 = verify source · publication date > year+2 = distant future.

    1. Add a book: tap 📷 Scan (phone) or enter an ISBN in the bottom bar (PC / USB scanner). Tap a cover to edit everything.

    2. Shelve: tap 📦 Shelving mode (⋯ on mobile) → enter “Bookcase / Shelf” → scan the whole shelf: automatic shelving.

    3. Back up: ☰ → 💾 Backup now (JSON). Export once a month.

    • ☰ Menu: 3 groups (Collection & capture · Back up & exchange · Professional & settings) + feature search at the top of the menu
