    🔑 Clés API — sources de données

    Chaque clé reste uniquement dans ce navigateur (localStorage) — jamais dans le code ni sur un serveur. Chaque utilisateur de l'application entre les siennes.

    Créer une clé : console.cloud.google.com → projet → API et services → Activer « Google Books API » → Identifiants → Clé API.
    Recommandé : restreindre la clé aux référants HTTP chenzu-ai.github.io/* et localhost.

    Le relais interroge Fnac + BnF (inaccessibles directement depuis un navigateur) via un micro-service gratuit Cloudflare Workers. Code et procédure : fichier worker.js du dépôt.

    Sources actives

    Toutes les sources actives sont interrogées en parallèle. Priorité de fusion : Google Books → BnF → Open Library ; chaque source complète les champs manquants des autres.

    📷 Photo d'étagère (IA)

    Photographiez l'étagère en paysage. L'IA lit les tranches et compare avec votre collection : ✅ déjà rangés ici · ⚠ censés être ailleurs · ❓ inconnus (recherche en 1 clic).

    ❓ Centre d'aide

    🚀 Démarrer (5 min)

    1. Ajouter un livre : bouton 📷 Scanner (téléphone) ou ISBN dans la barre du bas (PC / douchette USB). Cliquez une couverture pour tout modifier.

    2. Ranger : bouton 📦 Mode rangement (⋯ sur mobile) → indiquez « Meuble / Étagère » → scannez toute l'étagère : rangement automatique.

    3. Sauvegarder : ☰ → 💾 Sauvegarde immédiate (JSON). Faites un export par mois.

    📷 Ajouter des livres — toutes les voies

    • Scan caméra (+ ⚡ mode rafale) · Douchette USB · ➕ Sans ISBN

    • Photo d'étagère IA (☰ → 📷) : l'IA lit les tranches rangée par rangée — nécessite une IA vision (☰ → 🤖)

    • Import : ☰ → 📥 JSON (fusion) ou CSV (Libib/Excel)

    🤖 Reconnaissance — optimiser

    • Clé Google Books (☰ → 🔑) : résumés + couvertures, 1000 requêtes/jour gratuites

    • Relais BnF/Fnac (☰ → 🔑) : indispensable pour les livres FR d'avant 2010 — déployez worker.js sur Cloudflare Workers (gratuit)

    • Diagnostic ISBN (☰ → 🔑 → 🔍) : voyez ce que chaque source répond

    📚 Organiser

    • Étagères virtuelles, tags, favoris ♥, souhaits 🛒 · Séries (☰ → 👥) : tomes manquants, dispersion

    • Cote Dewey, collection, format, type d'édition (1ʳᵉ, collector, rare), prix éditeur · recherche plein texte

    📤 Prêts et inventaire

    • Prêter : fiche → « Prêté à… » + retour prévu. Rappels à l'ouverture · Réservations (« Réservé pour »)

    • Inventaire d'étagère (☰ → 🔎) : manquants / intrus / inconnus + historique
