# Banque de couvertures PrimAlph (privée)

Couvertures nommées par ISBN : `covers/<ISBN>.jpg` (max 600 px, JPEG ~80 %).

## Ajouter une couverture
Depuis l'app : fiche → 📷 « Importer une image » → bouton 🤝 **Partager avec la banque** (nécessite un token GitHub avec droits `repo` sur CE dépôt, collé dans ☰ → 🔑).

## Utilisation dans l'app
Le champ « URL banque » (☰ → 🔑) pointe vers l'URL brute du dossier `covers/` de ce dépôt. La chaîne de reconnaissance l'interroge en dernier recours : si `<URL>/<ISBN>.jpg` existe, la couverture est utilisée automatiquement.
